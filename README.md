# Lab 4 — LLMs and Prompt Engineering

This lab focused on using an LLM API to build a decision-support system for microfinance loan applications.

The system:
- Summarizes loan applications
- Extracts key information into JSON
- Identifies strengths, risks, and missing information
- Provides suggested next steps for a loan officer

I also tested the system for accuracy, reliability, and hallucinations, and considered the ethical risks of using AI for financial decisions.

## Files

- lab_4.ipynb — Main lab notebook
- prompts.py — Prompt templates used
- requirements.txt — Required Python packages
